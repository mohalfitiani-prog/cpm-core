## ما يزال غير مكتمل
- مراجعة قواعد Firestore وStorage الحالية قبل استبدالها، ثم نشر الوظائف والقواعد المناسبة.
- إعداد مزودي Authentication وبصمات Android وإدارة أول اشتراك.
- Firebase Web App ID لتطبيق CPM Core Admin وبناء واستضافة لوحة الإدارة.
- ترحيل الحسابات/البيانات القديمة من Room؛ لم يُنفّذ. يجب تدقيق تطابق تسجيل الدخول مع المتطلبات الأصلية، بما فيها تفعيل المكتب قبل اعتماد الإنتاج.
- اختبار على هاتف فعلي ومع الخادم المنشور. نجاح البناء والاختبارات لا يعني جاهزية الإنتاج.
